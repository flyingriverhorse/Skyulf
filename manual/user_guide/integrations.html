Integrations documentation index

Find every Databricks, MLflow and Spark guide here, including the preprocessing catalog used by generated projects. Each link includes a short description so you can choose a page without reading the whole documentation set.

For a first project, follow setup → data → training → model approval → scoring → monitoring. Add serving and online features when you need online requests. The guides below explain their own prerequisites, supported execution paths and configuration fields.

Score a large table on Spark workers Spark scoring: check admission, worker dependencies and execution settings.
Query a model through REST or SQL Serving endpoints: set up the endpoint and use REST or ai_query.
Find drift, performance loss or serving problems Monitoring overview: follow the store, enrollment, observations and dashboard flow.
Use Python without generating a Bundle Python SDK: fit, inspect and score from Python; choose the cloud operations you need.
