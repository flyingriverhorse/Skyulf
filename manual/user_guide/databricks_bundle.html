    Databricks Bundle guide index

    For all Databricks, MLflow, Spark and preprocessing guides with short page descriptions, open the integrations documentation index.

    Start with the end-to-end project guide to create a project, train a model and publish predictions. Before you generate one, choose a project shape: layout, prediction path and what runs on Spark. Use the topic pages below for a specific change. Generated project Markdown contains short instructions and links to these references.

    The project pins its Core version in deployment/requirements.txt. These public pages describe the current template; use the upgrade guide when the installed release differs. Training fits in one bounded Python process; distributed inference scores an admitted saved model on Spark workers.

    Monitoring and serving

    Detailed setup asks prediction_delivery: batch creates the score job, endpoint creates only the serving job, and both creates both. Quick setup defaults to batch. All choices keep monitoring. Logged endpoints created by the serving job enroll automatically after verification; observations still require requests and a monitoring run. See delivery choices and setup.
