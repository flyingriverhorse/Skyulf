# Changelog — 0.8.x Series

For the version index, see root [CHANGELOG.md](../CHANGELOG.md).

---

## v0.8.0

### 📦 Release

- **Version sync to 0.8.0** (app + frontend): root `pyproject.toml` bumped to
  `0.8.0` and `frontend/ml-canvas/package.json` / `package-lock.json` synced
  via `npm run sync-version`, keeping all three in lockstep for this release.

### 🧠 Core

- **skyulf-core 0.6.0** (`skyulf-core/setup.py`): the Growth initiative
  Wave 2 core release — null/NaN semantics fixes (F-01, F-04, F-05, F-06),
  lag/rolling stale-`y` fix (T1), `"variance"` alias (T2), `"uniform"`
  alias (T3), the registry contract test suite (T5), and datetime coercion
  (T6). All fixes were already verified in master; this version ships them
  under the `core-v0.6.0` tag. See the Stage 0 fix table in
  [changelog/0.7.x.md](0.7.x.md) (v0.7.8 section) for the full list.

### 📚 Docs

- **PyPI-ready README** (`skyulf-core/README.md`, growth plan A2.4): the
  quick start now builds its dataset inline with `pl.DataFrame(...)` instead
  of reading `customers.csv`, so the snippet runs verbatim for first-time
  readers; all 16 relative `examples/` links now point to absolute GitHub
  tree/blob URLs that resolve on PyPI; the docs badge and threshold-tuning
  link now point at the live `https://www.skyulf.com/manual` site instead of
  the 404-ing GitHub Pages URL; and the license section now correctly states
  AGPLv3+ (the root `LICENSE` is AGPLv3 — the old "Apache 2.0" line was
  wrong).
- **Notebook export surfaced in the README** (growth plan A2.5): new
  Features bullet describing the platform's notebook export — a runnable
  Jupyter file with your exact node config inlined, runnable in any Jupyter
  environment with `pip install skyulf-core`, no Skyulf platform required.
- **Packaging metadata** (`skyulf-core/setup.py`): the `Documentation`
  project URL now points at `https://www.skyulf.com/manual` (the old
  GitHub Pages URL 404s).

### 🧹 Cleanup

- No behavioral code changes in the app itself in this release — 0.8.0
  exists to ship the skyulf-core 0.6.0 release and the packaging/docs
  polish above.
