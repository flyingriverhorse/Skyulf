# Changelog — 0.8.x Series

For the version index, see root [CHANGELOG.md](../CHANGELOG.md).

---
## v0.8.16

- **Preprocessing library groups:** browse five collapsible task groups instead
  of one long list. Search reveals matching nodes and preserves group choices.
- **Guided canvas connections:** compatible ports highlight while dragging,
  rejected connections explain why, and output labels open a keyboard-accessible
  picker to connect an existing node or add the next step with one-step undo.
  Train/Test (plus enabled Validation) and X/y outputs join into one connection;
  split cards stay compact, and new steps stay near their source, with both nodes
  kept in view.
- **Profiling PII accessors:** `DatasetProfile` now exposes `has_pii`,
  `pii_columns`, and `pii_alerts` for direct consumer access.
- **PII phone false positives fixed (OC-148):** plain numeric IDs, ZIP+4
  values, and isolated phone-shaped values no longer trigger phone alerts.
- **PII profiling documentation:** the profiling comparison now links to a
  dedicated guide with runnable examples and the detector's advisory-only scope.
- **Find canvas components by task:** searches such as “normalize” and “fill blanks”
  work in the sidebar and Ctrl+K palette, with readable result descriptions.
- **Validation issues now open the exact setting:** reveal the node, open hidden
  sections, and focus the invalid field with an explanation; corrections keep focus.
- **Cleaner canvas connections:** delete controls appear on interaction, connections
  use compact readable labels, and technical IDs move into a header info menu
  with a copy action. Switching nodes no longer accumulates details in settings.
- **Cross-engine parity is enforced for applied preprocessing nodes (OC-76):**
  registry-wide checks now compare pandas and Polars outputs, including dtypes.
- **DummyEncoder and MissingIndicator dtypes are aligned across engines (OC-04):**
  binary indicators now preserve consistent `int8`/`int64` output contracts.
- **Bucketing output dtypes are aligned across engines (OC-04):** ordinal and
  bin-index outputs now use signed `int64` consistently.
- **Clustering handles cluster-local all-null features (OC-149):** Polars now
  matches pandas by preserving `NaN` centroid means instead of crashing.
- **GaussianMixture probability prediction honors clustering feature filtering
  (OC-196):** reference and non-numeric columns are removed consistently.
- **Wrapped pandas clustering preserves numeric features (OC-195):** text
  columns are dropped without losing the wrapped numeric frame.
- **Polars clustering crosstabs avoid reserved-name collisions (OC-197):**
  reference columns named `count` or `__skyulf_cluster__` are now supported.
- **DBSCAN noise is excluded from clustering metrics (OC-38):** label `-1` no
  longer counts as a cluster or participates in clustering-quality scores.

## v0.8.15

- **Canvas layout improvements:** resizable settings/results panels, responsive
  sidebar and toolbar, menus that fit smaller screens, and selected-node reveal.
- **Clearer canvas controls:** consistent button colors, improved action labels,
  searchable/collapsible component groups, and better keyboard access.
- **Refreshed themes and branding:** synchronized light/dark switching, charcoal
  dark mode with blue accents, the Skyulf logo, and aligned navbar dividers.
- **`py.typed` is included in `skyulf-core` (OC-78):** downstream type
  checkers now retain the package's annotations.
- **`joblib` is a direct dependency (OC-79):** it is now pinned at `>=1.3.0`
  wherever the project declares dependencies.
- **PowerTransformer safely writes float output (OC-05):** target columns are
  cast to `float64` before pandas assignment.
- **Schema inference tracks integer-to-float preprocessing outputs (OC-03):**
  shared dtype promotion logic keeps inferred schemas aligned with runtime.
- **TargetEncoder predicts schemas for continuous targets (OC-22):** the
  supported `"continuous"` value now replaces the invalid `"regression"` gate.
- **`Replace Invalid Values` no longer exposes an unused `invalid_values`
  parameter (OC-141).**
- **`skyulf-core` publishes Apache-2.0 metadata to PyPI (OC-81):** its wheel
  now includes the license expression and bundled license file.
- **License references are consistent:** backend and frontend are AGPLv3;
  `skyulf-core` is Apache-2.0.
- **Drift-computation failures are logged (OC-131):** PSI and KL fallbacks can
  no longer be mistaken silently for stable data.
- **PowerTransformer warns about missing fitted columns (OC-28):** both engines
  report the skipped columns and return the caller's frame.
- **Empty data-source filters are rejected (OC-159):** update and delete now
  raise `ValueError` before issuing an unscoped query.
- **CI now reports all failures and enforces 90% coverage (OC-77).**
- **Row-changing nodes keep `X` and `y` aligned (OC-163, OC-165, OC-166):**
  sorting and filtering share one position-based target selector.
- **DummyEncoder normalizes categories per value across both engines (OC-177):**
  float categories now match consistently. Refit artifacts created from
  explicitly selected float columns.
- **`get_fitted_split()` no longer mutates fitted pipeline state (OC-164):** it
  uses an isolated preprocessing chain.
- **Threshold-tuning docs now require a raw validation holdout (OC-207):**
  `get_fitted_split()` returns preprocessed data and must not feed this pipeline.
- **Threshold tuning warns when every candidate score ties:** its default
  `{0.5, 0.5}` result is no longer ambiguous.
- **Version 0.8.15 is synced across the root and frontend metadata.**
