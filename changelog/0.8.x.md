## v0.8.21

- **Portable category encoding (OC-271/299):** newly fitted DummyEncoder
  artifacts preserve Boolean and date/datetime categories across pandas and
  Polars, and automatic encoder selection includes native Enum columns.
  Refit affected encoders and downstream models to apply the new behavior;
  saved artifacts retain their existing category names.
- **Binning output safety (OC-276/283/284):** new range artifacts preserve
  category names across engines; reject collisions and ambiguous duplicate-edge
  labels, and retain the binned output when replacing a dropped source with an
  empty suffix. Refit legacy binning and downstream encoders/models together
  before changing engines.
- **Lossless date profiling (OC-273/305):** retain original strings when the
  selected date format cannot parse the full column, preventing fabricated
  missingness and Drop recommendations. Empty temporal bounds are actual nulls.
  Regenerate saved profiles; normalize mixed formats before temporal analysis.
- **Exact integer cleanup (OC-297):** infinity-only replacement preserves
  signed/unsigned integer values and dtypes, including values beyond Float64
  precision. Additional numeric rules and floating infinity replacement remain
  effective. Rerun affected transformations from the original data.
- **Canvas preview path labels:** include preprocessing outputs that feed a
  separate Data Preview node when assigning path letters, so their Canvas
  labels and Preview Results tabs agree. Use registered display names such as
  Resampling instead of technical type names such as Resampling Node.
- **Casting date and boolean text (OC-265/266):** preserve valid date strings
  on Polars and support boolean aliases in Categorical and Enum columns.
- **SMOTE + Tomek neighbors (OC-267):** apply the configured neighbor count
  to inner SMOTE and expose/validate the setting in Canvas.
- **Feature-selection target types (OC-256):** recognize pandas StringDtype
  and string Categorical targets as classification, including more than ten labels.
- **Calibrated ensemble refits (OC-268):** retain tuned calibration and nested
  base-model parameters during subsequent training and cross-validation.
- **Native missing features in tuning (OC-270):** inspect estimator support
  instead of a model-name allowlist, retaining old sklearn tag compatibility.
- **Threshold-aware fingerprints (OC-261):** include saved decision thresholds
  in pipeline identity. Recompute stored fingerprints for affected pipelines;
  model retraining is not required.
- **Merged-fold row alignment (OC-248):** reject branch configurations that
  sort or filter observations before a positional merge. Core and backend use
  the same admission checks; runtime row-count checks guard branch outputs.
- **Tuned class weights (OC-250):** apply nonnative class weights during all
  search strategies and final refitting using each fold's transformed training
  labels. Retrain affected tuned models to apply previously ignored weights.
- **Constant-feature PCA (OC-46):** report PCA as unavailable when prepared
  features have no variation, preventing NaN variance ratios in public JSON.
- **LabelEncoder target containers (OC-254):** apply target encoding to lists
  and NumPy arrays on either engine, preserving native Series metadata and
  leaving feature-only targets unchanged.
- **Antipodal distances (OC-263):** prevent floating-point roundoff from
  producing NaN Haversine distances for valid opposite points on Earth.
- **Threshold validation alignment (OC-249):** carry labels through the same
  sorting and filtering as validation features before choosing decision
  thresholds; reject mismatched raw row counts. Rerun threshold optimization
  if an affected pipeline previously saved a cutoff.
- **Single-class evaluation (OC-35):** omit undefined binary ROC curves and
  ROC AUC when a holdout contains one class, while retaining finite PR output.
- **PR-AUC tuning (OC-252):** align probability columns with the fitted model's
  classes when validation omits a class, including the binary positive class.
- **Decomposition column names (OC-258):** preserve groups named `value` or
  `ratio` through aggregation and drill-down; allow a numeric grouping column
  to serve as its own measure.
- **Dataframe wrapper restoration (OC-262):** load pickled/joblib pandas and
  Polars wrappers without recursion, preserving their data and native methods.
- **LightGBM row sampling (OC-187):** make `subsample` effective for GBDT/DART
  in basic training, all tuning strategies and final refitting. Preserve GOSS
  sampling, explicit frequency overrides and existing fitted models; retrain
  to apply a previously ignored fraction.
- **EDA decomposition missing groups (OC-192):** keep missing values separate
  from a literal `Unknown` category and use their identity when drilling down.
  The tree labels missing groups explicitly and retains them during navigation.
- **Split configuration warnings (OC-90):** warn when an unsupported public
  setting is ignored, including `stratify_col`; use `stratify` and
  `target_column` in node configs. Canvas sends only supported split settings
  plus routing metadata, so editor labels do not produce warnings.
- **Generated column collisions (OC-18):** reject conflicting one-hot, dummy,
  missing-indicator and multiclass target-encoding names before replacing
  existing data or emitting duplicate columns. Checks also apply at inference;
  names belonging only to dropped sources remain available.
- **Datetime output names (OC-30):** honor the configured output name, using
  it as a prefix for multiple features. Preserve existing columns with numbered
  suffixes unless overwrite is enabled. Refit saved pipelines affected by
  previously ignored names or overwritten columns.
- **Empty-data expectations (OC-48):** null, range and uniqueness checks
  reject zero-row datasets by default. Add `allow_empty=True` to calls that
  intentionally accept empty partitions; column-existence checks stay unchanged.
- **Calibrated base selection in tuning (OC-66 follow-up):** honor Base
  Estimator search choices in every strategy and final refit, including fold
  preprocessing. Random Forest selection no longer fails in Optuna/halving
  or silently trains logistic regression in Grid/Random search.
- **EDA transformation advice (OC-51):** choose transformations compatible
  with the value range and skew direction. Preparation recommendations now
  suppress the contradictory clean-dataset message, including target resampling.
- **Calibrated classifier seeds (OC-101):** apply `random_state` to stochastic
  base estimators during training, tuning and final refitting. Default 42 and
  explicit 0/None are respected; calibration CV splitting remains unchanged.
- **Invalid-value replacement (OC-140):** reject nonnumeric selections with
  a clear error before either engine can coerce text or compare it to numbers.
  Numeric text requires explicit conversion; temporal columns are excluded
  from automatic selection, and inactive configurations preserve their input.
- **Dataset Profile coverage (OC-59):** report supported numeric dtypes on
  both engines, including small/unsigned integers, binary, constant and
  entirely missing numeric columns. Rerun the node to refresh saved profiles.
- **Binning missing labels (OC-60):** honor the configured missing label on
  Polars for null, NaN and out-of-range bins. Label mode consistently returns
  strings on Polars; pandas retains mixed numeric/text values and the default
  keep strategy is unchanged.
- **Group aggregation regressions (OC-24):** verify the existing shared
  null/NaN training group and fitted-only inference behavior across both engines.
- **EDA string categories (OC-110):** recognize repeated labels in small
  datasets so categorical statistics and classification target analysis are
  available. Infer from non-missing values; preserve unique strings as text.
  Rerun saved analyses to refresh their results.
- **EDA category counts (OC-247):** exclude missing values from distinct and
  rare-label counts and keep them from displacing observed top categories.
- **Decimal preprocessing (OC-120):** include Decimal columns in numeric
  auto-selection on both engines and handle selected values and missingness
  safely through scaling, imputation, outlier handling and binning. Numeric
  calculations use float64; source frames retain exact Decimal values. Refit
  affected pipelines to include columns omitted by older fitted artifacts.
- **Enum text cleaning (OC-121):** include Polars Enum columns in automatic
  TextCleaning and AliasReplacement selection, matching pandas categorical
  strings. Preserve missing values and explicit empty selections; refit saved
  artifacts that previously omitted Enum columns.

  optimize and apply decision thresholds after a hyperparameter search, using
  the fitted classifier's labels for binary and multiclass predictions.

  the score column and each row's value when pandas indexes contain duplicates.

  states, repeated controls have contextual names, and keyboard users can
  browse for a dataset file and return from upload/settings/results panels.
  Modeling help and parameter history preserve keyboard focus.
- **PII review in profiling:** inspect flagged columns, detector category,
  severity, and advisory explanations without rendering raw values or samples.
  Existing data-quality alerts remain available in the Dashboard.
- **Canvas CI fixes:** split labels reserve their measured width across system
  fonts; sidebar tests open collapsed preprocessing groups. Threshold tests
  locate the checkbox by its label, and large inspection-table tests verify
  rendering limits without expensive visibility checks on every cell.
- **Clearer canvas execution:** review model names and Train/Tune modes before
  queuing experiments. Preview issues and experiment status live in the
  notification center. Compact training controls expand at the end of settings;
  node runs keep their model history tab, while Run all groups submitted jobs.
- **One notification center:** app messages use the top-right bell instead of
  pop-up toasts, with no duplicate preview/run notices and access on every page.
- **Text cleaning/encoding fixes (OC-122, OC-179–182):** unknown
  `TextCleaning` operations now fail validation; `DummyEncoder(drop_first=True)`
  is engine-parity for single-category columns; nullable dates in
  `normalize_slash_dates` no longer crash; boolean replacement maps only parse
  declared keys; and string columns (`StringDtype`) are correctly detected for
  dummy/hash auto-encoding.
- **Cross-validation failure reporting (OC-145):** post-tuning CV errors now
  fail the training node and pipeline instead of returning success with missing
  `cv_*` metrics.
- **Standalone leakage enforcement (OC-70):** core `fit()` and
  `get_fitted_split()` now reject learned preprocessing before a configured
  train/test splitter by default; `on_leakage="warn"` or `"ignore"` are explicit
  compatibility overrides. Stateless nodes and target-only encoders no longer
  produce false positives. A shared JSON fixture covers all registered nodes
  and models in core/API leakage integration tests.
- **Leakage error feedback (OC-70):** canvas submission errors retain the backend
  explanation. Selected-model preflight checks only that model's ancestors,
  while Run All continues to validate the full graph.
- **Branch-aware leakage validation (OC-70):** every training branch now needs
  its own train/test splitter or explicit cross-validation; data-dependent
  nodes on an unprotected branch are reported before execution. The user guide
  now documents the branch behavior and `DataLoader → StandardScaler` example.

- **Polynomial preprocessing placement:** `PolynomialFeatures` and its
  `PolynomialFeaturesNode` alias now require a row split before automatic column
  selection (`auto_detect=True` with omitted or empty columns). Explicit nonempty
  columns or disabled/omitted automatic detection remain fixed operations.
  Canvas validation and placement guides reflect this configuration distinction.
- **Original split membership survives composite preprocessing:** the backend
  persists the first actual `SplitDataset` before later transforms. Fold refits
  reload its exact train/test/validation membership, including unseeded splits.
  Missing or corrupt snapshots follow the configured `raise`/`warn`/`ignore`
  policy instead of silently creating a new split.
- **Data-independent pandas constant imputation:** constant mode preserves
  all-missing columns with `keep_empty_features=True` and derives explicit fills
  from configuration rather than fitted missingness. Scikit-learn fitting still
  handles validation and default fill values; mean/median modes continue to learn
  training-set statistics.
- **Preprocessing replay consistency:** calendar extraction parses each value
  independently of companion rows, and nullable ISO weeks preserve generated
  features. Label, ordinal, WOE and hash encoding use versioned category keys
  that keep numeric values stable across batches while preserving legacy replay.
- **Nullable encoding and text inputs:** categorical missing values no longer
  break one-hot encoding, vectorizers or tokenization. WOE rejects missing
  targets instead of silently counting them as a negative class; categorical
  casting preserves numeric identity without conflating numeric-looking strings.
- **Explicit imputation and row filtering:** mean/median imputation retains
  explicitly selected binary, constant and singleton numeric columns. Row
  cleaning preserves list/NumPy target types, positions and empty-array shapes.
- **Focused node information:** Escape closes the identifier popover and returns
  focus to its opener even when a background connection tooltip appears later.
- **Runnable leakage examples:** Example 09 and its notebook retain their safety
  checks under optimized Python execution. Merge regression tests distinguish
  safe fixed transformations from learned raw forks without relaxing strict
  per-fold leakage protection.
