# Changelog — 0.2.x Series

For the version index, see root [CHANGELOG.md](../CHANGELOG.md).

## v0.2.0 — Data Drift Redesign

### 📊 Drift Page
- Job selector with date-grouped dropdown, model type badges, best metric, target column, and descriptions.
- PATCH endpoint for job descriptions. Inline description editing. Search across dataset name, job ID, description, model type, target.

### 📈 Drift History
- `DriftCheckResult` DB model persists every drift calculation. History endpoint returns past checks per job.
- Timeline chart shows drifted-column count and drift % over time when 2+ checks exist.

### 🎯 Feature Importance × Drift Risk
- Feature importances extracted from fitted models and saved in metrics. Enriched drift response overlays importance.
- Risk badge per feature (High/Medium/Low) with importance bar visualization.

### 🔧 Backend
- `n_rows` and `n_features` saved to metrics for monitoring display. `typing.cast` for mypy compliance.

### 📈 Drift UX
- Summary cards (Total Columns, Drifted Count, Avg PSI, Most Drifted). "Show Only Drifted" filter.
- Sortable metric columns. Empty state placeholder. Collapsible schema drift sections. `useMemo` performance.
- CSV export of drift report. Custom drift thresholds panel. Sidebar alert badge with lightweight `/drift/status` endpoint.
- Per-column historical PSI sparklines. Client-side threshold re-evaluation.
