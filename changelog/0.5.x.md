## v0.5.18 — Core Backend Hardening

### 🐛 Bug Fixes
- `MAX_UPLOAD_SIZE` raised 1 GB → 10 GB, env-var configurable. Content-Length early reject. Actionable 413 error.
- Docker Compose `MAX_UPLOAD_SIZE` explicitly set. Transformer smoke test now dynamically excludes Modeling nodes.

### 🔧 Backend
- `ArtifactDiscovery` abstraction for root-level job-folder scanning. `monitoring/router.py` uses seam, not `Path.iterdir()`.

### 🧹 Hygiene
- Removed dead no-op wrapper in `data_service.py`. Removed redundant `import time` in `health/routes.py`.

### 🧩 skyulf-core
- No more inline engine branches in `bucketing.py`/`split.py`. Regression guard test added.
- `SchemaMismatchError` + `SkyulfSchema.assert_compatible()`. `SkyulfPipeline.describe()` + `to_mermaid()`.
- `skyulf.profiling.expect` module (column/null/range/unique assertions). `skyulf.core.deprecation` module.
- Schema-inference fuzz test (hypothesis). Module-boundary docstrings.

### 🧱 skyulf-core — Sub-package splits
- 8 fat preprocessing modules split into sub-packages. Framework concerns relocated to `skyulf/core/`.

### 🆕 skyulf-core — Time-series nodes
- `LagFeatures`, `RollingAggregate`, `DateFeatures` nodes (dual-engine). 9 tests.

### ⚡ Performance
- `pytest-benchmark` harness for preprocessing + modeling across engines.

### 🎨 Frontend
- WOE/IV encoding in canvas with target-column selector. `CalibratedClassifier` search space + selectable base estimator.
- `TimeSeriesNode` with method selector (Lag/Rolling/Date features).
