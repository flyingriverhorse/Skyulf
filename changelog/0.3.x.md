# Changelog — 0.3.x Series

For the version index, see root [CHANGELOG.md](../CHANGELOG.md).

---

## v0.3.0 — Multi-Path Canvas Execution

### 🔧 Backend
- Training nodes consume all upstream inputs via `_resolve_all_inputs()` and `_merge_inputs()`.
- Auto-merge: column-wise concat when row counts match, row-wise when columns match. Duplicate columns deduplicated.
- Clear errors on incompatible inputs. Topological input ordering.

### 🎨 Frontend
- Merge indicator badge (⊕) with input count on multi-input nodes. Model-to-model connections blocked.

### 🐛 Bug Fixes
- Dead-end branches (connected to dataset but not to any terminal) excluded from execution.

## v0.3.1 — Multi-Path Hardening

### 🔧 Backend
- Empty DataFrame guard in `_merge_inputs()`. Better error messages for model artifact detection.

### 🎨 Frontend
- Merge badge tooltip shows "Merging data from N upstream sources". Render performance via shallow equality.
- Badge counts unique source nodes instead of raw edges.
