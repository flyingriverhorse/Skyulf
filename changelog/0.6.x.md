## v0.6.9 — Six Audit Rounds

### 🔴 Critical/High Fixes
- Polars `SplitDataset` test/val splits silently dropped from `evaluate()`.
- `time_series_split` leaked time column & broke chronological order on Polars.
- Drift PSI/KL reported zero when column shifted outside reference range.
- Pandas `with_column()`/`__setitem__` corrupted data on mismatched index.
- Casting narrow int dtypes silently uncast; unsigned narrow wraps around via modulo.
- Model registry TOCTOU race on version allocation. Path-traversal in pipeline JSON storage.
- `DateFeatures` all-null on Polars for plain date strings.
- 3 of 5 `InvalidValueReplacementNode` dropdown modes were silent no-ops.

### 🟠 Medium Fixes
- Polars boolean casting from strings crash. `IterativeImputer` ignored `random_state`.
- Casting Polars path silently no-op'd on unsupported dtypes in strict mode.
- `MissingIndicator.flag_suffix` accepted but never applied. Path-traversal in dataset sampling.
- Removed `.pkl`/`.pickle`/`.h5`/`.hdf5` from upload allow-list.
- Evaluation results served across `job_id` mismatch. Pipeline crashes left jobs stuck "running".
- Polars `with_column()` crash on bare scalar.

### 🟡 Low / Observability Fixes
- Bucketing swallowed per-column exceptions. `DataSplitter` didn't validate split sizes.
- `LabelEncoder` pandas upcast to float64 on unseen categories. `select("col")` return type normalized.
- Default rate limit (200/min). Predict payload cap (10k rows). Health `environment` from real name.
- Exception handlers used stale `sys.exc_info()`. Celery DB engine init race.
- Categorical profiling top_k by name. Missing solver in UI auto-picked.
- `TuningApplier.predict()` Polars crash. `EngineRegistry.set_active_engine()`. Orphaned-file cleanup logged.

### 🧹 Cleanup
- ~14 hardcoded constants moved to `Settings`. `ruff format` drift (51 files). Dependabot queue merged.

### Also Fixed (Rounds 1-3)
- Profiling: unmatched filters, `exclude_cols`, target-imbalance top-10, Boolean-target skip, "Possible ID" dead code, correlation truncation, univariate/model-based `fillna(0)`.
- Tuning/CV: ignored `cv_shuffle`/`cv_random_state`, silent fallback to defaults, fold failures as 0.0, multiclass ROC/PR AUC missing, binary metrics omitted for non-{0,1}.
- Engine: registration races, `SkyulfSchema.rename()` duplicates, dtype-extraction silent, `pack_pipeline_output` NaN-padding, `SplitDataset.copy()` reference leak, substring engine matching.
- Other: `EDAVisualizer.plot()` figure leak, geospatial out-of-range lat/lon, ambiguous date-format ties, rule-discovery ordinal thresholds, drift categorical/text skip, `season`/`time_of_day`/`minute`/`second` in UI.
