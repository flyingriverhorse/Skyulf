## v0.4.1 — Aggregate Job Progress Badge

### 🎨 Frontend
- Parallel run progress banner in JobsDrawer with Zap icon, branch counts, and animated progress bar.
- `useJobStore` gains `activeParallelRun` state. Run All Experiments sets the tracker immediately.
- Consistent search icon centering across all pages. DataSources and Jobs page filters with active count badges.

## v0.4.0 — Parallel Experiment Execution

### 🔧 Backend
- `partition_parallel_pipeline()` splits into independent sub-pipelines. Hybrid partitioning for mixed terminals.
- Multi-job API returns `job_ids[]`. Branch ancestry via BFS. Target node filtering for individual Train buttons.

### 🎨 Frontend
- Merge/Parallel toggle on training nodes with 2+ inputs. GitFork badge for parallel mode, Merge badge otherwise.
- Run All Experiments toolbar button. Parallel branch count feedback. Pipeline serialization passes `execution_mode`.

### 🧪 Tests
- 11 tests: ancestor collection, no-partition, multi-terminal, shared prefixes, parallel splitting, metadata.

### 🎯 UX
- Ctrl+C/V node copy-paste with position offset. Branch edge coloring via golden-angle HSL.
- Branch labels near terminals. "Advanced Tuning" renamed to "Advanced Training" everywhere.
- Feature Importance tab in Experiments showing top 15 features across selected jobs.
