Questions from the audience.

Which interface should I start with?

Start with the live platform when you want to understand the whole workspace quickly. Start with skyulf-core when your immediate work already lives in Python.

Can the two interfaces be used together?

Yes. That is the central product idea. The platform provides visual and operational context; skyulf-core and notebook export preserve code ownership.

Where does Skyulf run?

The hosted demo is available for evaluation. The platform can run locally or be self-hosted, while skyulf-core installs from PyPI.
