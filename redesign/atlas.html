A file arrives and nobody knows what is in it.

Load CSV, Excel, JSON, Parquet, or read straight from S3-compatible storage. Skyulf profiles the columns and shows you the dataset's actual condition before you write a single transformation against your assumptions about it.

Exploration done properly, not done quickly.

Automated EDA covers the ground you would cover if there were time: statistical profiling, distributions, correlations, outliers, segmentation, target analysis, and causal discovery.

You arrive at the modeling step already knowing which features carry signal and which columns are going to embarrass you later.

The pipeline is a graph, so the order is visible.

Preprocessing, feature engineering, splitting, and modeling are nodes you connect. Seeing the sequence is the point: leakage is an ordering mistake, and ordering mistakes are hard to spot in a notebook and hard to miss on a canvas.

Training runs in the background through Celery and Redis, or on background threads when the deployment is small.

Runs you can compare beat runs you have to recall.

Each training run keeps its metrics, parameters, and feature importance beside the pipeline that produced it. Promotion into the registry becomes a comparison rather than an archaeology exercise across four filenames.

The route does not end at a good score.

Registry with version history, deployment, inference, drift monitoring, audit history, and operational diagnostics all live in the same project as the pipeline. When something moves in production, the thing that produced it is one click away, not one team away.

  • Version historyEvery registered model keeps the versions behind it.
  • DiagnosticsNode-level timings show which step is actually slow.
  • Audit trailWhat changed, when, and on which run.

One engine, and two ways to travel it.

The visual platform and the Python package are not a product and its demo. They are the same workflow, and you can move between them whenever the work changes shape.

skyulf-core

The engine alone, in your own scripts and notebooks. Polars-friendly, built on scikit-learn rather than replacing it.

# pip install skyulf-core
from skyulf import SkyulfPipeline

pipeline = SkyulfPipeline({
    "preprocessing": [
        {"name": "split", "transformer": "TrainTestSplitter",
         "params": {"target_column": "purchased"}},
    ],
    "modeling": {"type": "logistic_regression"},
})
pipeline.fit(customers, target_column="purchased")
pipeline.save("customer_model.pkl")
