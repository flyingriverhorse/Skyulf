Your data never leaves your machines

Skyulf is a self-hosted platform for the entire machine learning workflow — profiling a raw file, automated exploration, node-based pipelines, model training and comparison, then deployment, inference, and drift monitoring.

The same engine ships separately as skyulf-core, an Apache-2.0 Python package. Nothing you build gets trapped in the canvas: every pipeline exports to a Jupyter notebook.

No signup on the demo. Run it locally with the repository start scripts, or self-host the whole stack with Docker Compose.

Know the dataset before you model it

Load CSV, Excel, JSON, Parquet, or read from S3-compatible storage. Then let the automated EDA do the survey you never have time to finish by hand.

Statistical profiling, distributions, correlations, outliers, segmentation, target analysis, feature importance, and causal discovery — generated from the dataset rather than assembled chart by chart.

  • Distributions and correlations across every column
  • Outlier and segmentation analysis
  • Target analysis and feature importance
  • Causal discovery between variables

A pipeline you can point at

Preprocessing, feature engineering, splitting, and modeling as connected nodes — so the order of operations is something you can see rather than something you hope you got right.

Leakage is an ordering mistake. It is nearly invisible in nine hundred lines of notebook and hard to miss on a graph. Training runs in the background through Celery and Redis, or on background threads when the deployment is small.

Every run keeps its metrics, parameters, and feature importance next to the pipeline that produced it, so choosing a model is a comparison instead of an excavation.

  • Node-based preprocessing and feature engineering
  • Background training, with a visible job queue
  • Side-by-side experiment comparison
  • Node-level diagnostics for slow steps

Training is the short part

Registry with version history, deployment, inference, drift monitoring, audit history, and operational diagnostics — in the same project that produced the model, not a second stack you bolt on afterwards.

  • Model registry with full version history
  • Deployment and inference inside the platform
  • Drift monitoring against training distributions
  • Audit history of what changed and when
  • Artifacts on local disk or your own S3-compatible storage
  • SQLite to start, PostgreSQL when it grows

skyulf-core

The engine on its own. Polars-friendly, built on scikit-learn rather than replacing it. Python 3.12+.

# pip install skyulf-core
from skyulf import SkyulfPipeline

pipeline = SkyulfPipeline({
    "preprocessing": [
        {"name": "split",
         "transformer": "TrainTestSplitter",
         "params": {"target_column": "purchased"}},
    ],
    "modeling": {"type": "logistic_regression"},
})
pipeline.fit(customers, target_column="purchased")
pipeline.save("customer_model.pkl")
