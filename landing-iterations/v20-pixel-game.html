"Is this game free?"

Free as in freedom! skyulf-core is Apache-2.0, the Platform is AGPLv3. git clone + docker compose up and the quest begins at home.

Notebooks are the practice mode. In the ranked ladder of production, you need to know which data fitted your scaler — and Skyulf's registry always knows.

"What are the system requirements?"

Python 3.12, a scikit-learn engine, pandas or Polars. Runs on any machine that can run Docker.
