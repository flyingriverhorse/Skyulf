From raw CSV to a monitored model.

Skyulf wraps scikit-learn in pipelines you can trust — designed on a canvas or written in plain Python, checked for data leakage, versioned, deployed and watched for drift. Self-hosted. Open source.

1Ingest

Point it at a file

CSV, Excel, JSON, Parquet or an S3-compatible bucket. Skyulf reads it with Polars, profiles the columns and keeps every version you load — so you always know which data produced which model.

2Explore

Understand it first

One click profiles every column: distributions, correlations, outliers, interactions, clusters. Surrogate trees and causal discovery show which relationships actually drive your target.

3Build

Design, don't retype

Drag 35 node types onto the canvas and connect them. Branch to try two feature strategies side by side. Validation blocks bad runs before they waste your time — and exports everything to a notebook.

4Train

Background training

Runs execute as jobs, so the UI never freezes. Grid, random, halving or Optuna search — each trial reports as it finishes, with nested tuning for ensembles.

5Compare

Pick a winner on evidence

Every run keeps metrics, curves and confusion matrix. See which change actually helped, and tune decision thresholds instead of accepting 0.5.

6Deploy

Promote and serve

Models land in a registry with versions and artifacts. Promote one to active — it serves behind a REST endpoint. Full deployment history, so rollback is a decision, not archaeology.

7Monitor

Find out before users do

Live data compared against the training baseline, column by column — four drift tests each. Error log, slow-node profiler, and an audit trail of every change.

the bug that doesn't raise an error

Your model says 94%.
Production says 71%.

✕ Leaked pipeline

94%

Imputer, scaler and encoder fitted before the split. They learned from the test rows. The validation score includes answers it was supposed to be guessing. The code runs fine — the number just isn't real.

✓ Skyulf pipeline

71%

Every node is split into a part that learns and a part that applies. Learning only ever sees training data, and what it learned is saved as explicit parameters. The score you ship is the score you keep.

▲ validate_leakage_safety() — Step 0 ('SimpleImputer') is configured before the train/test split (step 1, 'TrainTestSplitter') and will fit its statistics on the full dataset including the test set — move it after the splitter.

before you try it

Fair questions.

What is Skyulf?

Two things sharing one engine: skyulf-core, a Python library giving you a single pipeline API over scikit-learn, and a self-hosted workspace where you build that same pipeline on a canvas.

Do I have to self-host it?

Try the hosted demo first — nothing to install. For real work, docker compose up takes a few minutes. Your data never leaves your machine: usable in hospitals, banks, anywhere the data legally cannot go to a third party.

Is this really free?

Yes. skyulf-core is Apache 2.0 — use it in anything, including closed-source commercial products. The platform is AGPLv3, so improvements to the application itself are shared back.

Can I use it in production?

Perfect for internal tools, research and experimentation. A stable v1.0 for critical production workloads is in progress.

How do I contribute?

Start at GitHub. Code, docs, bug reports or ideas — every contribution shapes Skyulf.
