Information desk

Is Skyulf free?

Yes. skyulf-core is Apache-2.0; the Platform is AGPLv3. Self-host: git clone, then docker compose up. No ticket required.

Is it enterprise-ready?

It's honest v0.1 — real code, 2,266 passing tests, real documentation. We don't announce flights we can't fly.

Why not just use a notebook?

Notebooks are carry-on: fine for the trip, terrible as the plane. Skyulf's registry knows which data fitted which scaler — by construction, not by memory.

What does it run on?

Python 3.12, scikit-learn engine, pandas or Polars dataframes. SHAP, Optuna, and notebook export all aboard.
