An encoder fitted before the split leaks labels into validation. The notebook says 94%. Production says otherwise. Skyulf splits every node into learn and apply, scans the graph with validate_leakage_safety(), and records a fingerprint + model card — so the number you validate is the number you ship.

Is Skyulf free?

Yes. The platform is AGPLv3 and self-hosted; skyulf-core is Apache-2.0. No accounts, no cloud, no paid tier.

Does it replace scikit-learn?

No. It runs on scikit-learn. Pipelines compile to standard sklearn objects, so you can leave with working code any time.

How do I run it locally?

git clone https://github.com/flyingriverhorse/skyulf && cd skyulf && docker compose up

What data does it accept?

CSV and Parquet tabular data via pandas or Polars, plus text columns for NLP nodes. Python 3.12.
