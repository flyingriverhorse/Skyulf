Friendly questions

The ones everyone asks first.

Is it really free?

Yes — the platform is AGPLv3 and self-hosted, the library is Apache-2.0. No accounts, no cloud bills, no tiers.

Will I be locked in?

Nope. Pipelines compile to plain scikit-learn objects, and you can export the whole thing to a notebook whenever you like.

How do I run it on my machine?

git clone https://github.com/flyingriverhorse/skyulf, then docker compose up. That's the whole ceremony.

What data can I feed it?

CSV and Parquet through pandas or Polars, plus text columns for the NLP nodes. Python 3.12 under the hood.
