Continue? FAQ

Is it free?

Yes. Platform is AGPLv3 and self-hosted, library is Apache-2.0. Zero cost, zero accounts.

Am I locked in?

No. Pipelines compile to plain scikit-learn. Export a notebook and leave with your code whenever you want.

Local co-op setup?

git clone https://github.com/flyingriverhorse/skyulf && docker compose up

Supported data?

CSV and Parquet via pandas or Polars, plus text columns for NLP nodes. Python 3.12.
