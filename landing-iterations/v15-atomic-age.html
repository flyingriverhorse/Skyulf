A word of warning, friend!

Not all accuracy is what it claims to be. Read these two order tickets carefully — one of them is cheating on you.

Order #94 — "Leak special"

94%

Looks scrumptious! Unfortunately the scaler peeked at the test set, so this number is pure fiction. The 71% you get in production is the real bill.

RETURN TO SENDER

Order #71 — "The honest plate"

71%

Modest, yes. But every digit was earned on data the pipeline never saw. This is the number you can serve to the family with pride.

Questions from the audience

Is it really free?

Truly! skyulf-core is Apache-2.0 and the Platform is AGPLv3. Self-host everything for zero dollars: git clone, then docker compose up.

Is it enterprise-ready?

Skyulf ships honest v0.1 software: a real codebase, real tests, real docs — and no pretend "battle-tested at planetary scale" claims. You can read every line yourself.

Why not just write a notebook?

Notebooks are splendid for exploring. But the moment a notebook goes to production, someone must answer "which data fitted this scaler?" Skyulf's registry answers it by construction.

Which Python does it want?

Python 3.12, with pandas or Polars dataframes — your choice.
