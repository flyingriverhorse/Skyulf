Section E

Field questions

Answered as written. No footnotes.

Is Skyulf free?

Yes. Platform is AGPLv3 and self-hosted; skyulf-core is Apache-2.0. No accounts, no cloud, no paid tier.

Does it lock me in?

No. Pipelines compile to standard scikit-learn objects. Export to a notebook and walk away with working code at any time.

How do I run it locally?

git clone https://github.com/flyingriverhorse/skyulf && cd skyulf && docker compose up

What inputs does it take?

CSV and Parquet tabular data through pandas or Polars, plus text columns for NLP nodes. Runs on Python 3.12.
