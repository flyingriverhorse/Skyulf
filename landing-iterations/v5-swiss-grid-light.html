The standalone Python library

No server, no UI, no lock-in. One consistent pipeline API over scikit-learn for your scripts and notebooks, with leakage checks and artifacts built in.

  • Works standalone in any notebook or script
  • Accepts pandas or Polars frames directly
  • Permissive license — ship it inside your own product
from skyulf import SkyulfPipeline
p = SkyulfPipeline({...})
p.validate_leakage_safety()  # []
p.fit(df, target_column="target")

Section02

From a raw file to a monitored model.

Every stage lives in one workspace, so nothing gets lost between a notebook, a spreadsheet of results and whatever is actually running in production.

/01

Ingest

CSV, Excel, JSON, Parquet or S3-compatible buckets. Read with Polars, columns profiled, every dataset version kept for traceability.

/02

Explore

Distributions, correlations, outliers, interactions, clusters. Surrogate decision trees and causal discovery show what drives the target.

/03

Build

Drag nodes, connect them, branch the pipeline. Per-node validation with the fix pointed out for you.

/04

Train & tune

Background jobs keep the UI free. Grid, random, halving or Optuna search with live trial output and nested ensemble tuning.

/05

Compare

Metrics, curves and confusion matrix per run. Tune decision thresholds on a held-out set instead of accepting 0.5.

/06

Deploy

Registry with versions and artifacts. Promote a version to active; it serves behind a REST endpoint. Full history for audit.

/07

Monitor

Four drift tests per column against the training baseline. Error log, slow-node profiler and an audit trail of every change.

Section03

The bug that doesn't raise an error.

Fill missing values or scale a column before the train/test split, and those steps quietly learn from the test rows. The code runs fine. The number just isn't real.

LEAKED PIPELINE
Validation ROC-AUC 0.94 — imputer fitted on the full dataset, including rows reserved for testing. Production accuracy later: 0.71.
SKYULF PIPELINE
Validation ROC-AUC 0.71 — every node split into a part that learns and a part that applies. Learning only ever sees training data.
STATIC CHECK
validate_leakage_safety() inspects pipeline order and reports, in plain language, which step must move after the splitter — on the canvas and in the library.
ARTIFACTS
Fingerprint (data + steps + model hash), exportable model card, learned parameters stored explicitly so inference never refits.
DRIFT DETECTION
Kolmogorov-Smirnov, PSI, Wasserstein distance and KL divergence — each with its own threshold — per column, against the training baseline.
"Your model says 94%. Production says 71%. Usually nothing is broken — the score was just measured wrong, and nothing in a normal notebook tells you that." — Why Skyulf checks pipeline order by construction

Section05

Frequently asked questions.

What is Skyulf?

Two things that share one engine: skyulf-core, a Python library giving you a single pipeline API over scikit-learn, and a self-hosted workspace where you build that same pipeline on a canvas.

Do I have to self-host it?

You can try the hosted demo first with nothing to install. For real work, docker compose up takes a few minutes. Because it runs on your machine or server, your data never has to leave it — usable in hospitals, banks, anywhere the data legally cannot go to a third party.

Is this really free?

Yes. skyulf-core is Apache 2.0 — use it in anything, including closed-source commercial products. The platform is AGPLv3, so improvements to the application itself are shared back.

Can I use it in production?

It is perfect for internal tools, research and experimentation. A stable v1.0 for critical production workloads is in progress.

How can I contribute?

Start at GitHub. Code, documentation, bug reports or feature ideas — every contribution helps shape Skyulf.

Ready to build?

Try the demo in your browser, or install the library and start from your next notebook. No signup, no per-prediction bill.
