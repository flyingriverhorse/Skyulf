The leakage exposé

An exclusive: the 94% score that never existed.

Fake news
94%

The leaked pipeline. The encoder saw the labels before the split. Validation was a lie; production corrected it to 71%.

  • Encoder fitted pre-split
  • Labels bleed into validation
  • Nobody notices until launch
Verified
71%

The Skyulf pipeline. learn/apply split on every node, plus a static scan: validate_leakage_safety(). The score survives production.

  • Leakage paths rejected at build time
  • Fingerprint + model card per run
  • Validation = production

Is it really free?

Yes. Platform AGPLv3, library Apache-2.0. Self-hosted, no accounts, no cloud.

Lock-in?

None. Pipelines compile to plain scikit-learn; export a notebook and keep your code.

Local setup?

git clone https://github.com/flyingriverhorse/skyulf && docker compose up

Data formats?

CSV / Parquet via pandas or Polars, plus text columns. Python 3.12.
