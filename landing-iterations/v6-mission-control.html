the silent killer of ml

Data leakage inflates your score. Skyulf catches it before you ship.

A target encoder fitted on the full dataset before the split quietly leaks labels into validation. The score looks fantastic — until production.

Skyulf splits every node into learn and apply phases, then statically scans the graph with validate_leakage_safety().

94%
leaked validation
71%
honest production
$ skyulf validate pipeline.json

[scan] TargetEncoder fitted pre-split ... LEAK DETECTED
[scan] validate_leakage_safety() ....... FAILED

[fix ] learn/apply split enforced
[fix ] encoder moved inside cv folds

$ skyulf validate pipeline.json

[scan] validate_leakage_safety() ....... PASSED
[result] honest score 0.71 — not 0.94
[write] fingerprint + model card saved

FAQ

Straight answers, no marketing.

Is Skyulf really free?

Yes. The platform is AGPLv3 and self-hosted; skyulf-core is Apache-2.0. No accounts, no cloud dependency, no paid tier.

Does it replace scikit-learn?

No — it runs on scikit-learn. Pipelines compile to standard sklearn objects, so you can leave any time with working code.

How do I run it locally?

git clone https://github.com/flyingriverhorse/skyulf && cd skyulf && docker compose up

What data formats are supported?

CSV and Parquet tabular data via pandas or Polars, plus text columns for NLP nodes. Python 3.12 runtime.
