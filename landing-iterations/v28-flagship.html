Data to deployment.One workflow, two interfaces.

Skyulf connects the machine-learning lifecycle — exploration, pipelines, training, comparison, deployment, and monitoring — as a self-hosted visual platform and an independent Apache-2.0 Python package.

Open the live demo — no signup $ pip install skyulf-core

No black box. Visual work exports to Jupyter. Start on SQLite, grow to PostgreSQL. Store data locally or in S3-compatible storage.

Visual platform

SELF-HOSTED

A node-canvas workspace for the whole lifecycle, served from your own infrastructure.

  • Node-based preprocessing, feature engineering, splitting, modeling
  • Background training via Celery + Redis or threads
  • Registry, deployment, inference, drift, audit history

skyulf-core

APACHE-2.0

The same engine as an independent Python package, for scripts and notebooks.

  • Automated EDA: profiling, correlations, outliers, causal discovery
  • Build and run pipelines without the web platform
  • Install from PyPI; no account, no lock-in
$ pip install skyulf-core

The lifecycle, connected.

Eight stages, one continuous line. Nothing is re-exported between tools because nothing leaves the workflow.

01

Ingest

CSV, Excel, JSON, Parquet, and S3-compatible storage land in one place you control.

02

Explore

Automated EDA: statistical profiling, distributions, correlations, outliers, segmentation, causal discovery, target analysis.

03

Pipeline

Node-based preprocessing, feature engineering, splitting, and modeling on a visual canvas.

04

Train

Background training through Celery and Redis, or background threads for lighter setups.

05

Compare

Experiments side by side, so a model choice is a decision with evidence.

06

Registry

A model registry with version history and audit trail.

07

Deploy & infer

Ship a model and serve inference from the same workspace.

08

Monitor

Drift monitoring and operational diagnostics keep the workflow honest after launch.

Nothing is trapped.

Every visual pipeline exports to a Jupyter notebook — full or compact. Your work stays yours, in a format the whole ecosystem already reads.

Visual work remains portable through notebook export rather than being trapped inside the canvas.
