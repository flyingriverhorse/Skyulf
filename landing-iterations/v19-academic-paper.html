Skyulf: A Visual Platform for Leakage-Safe Machine Learning Pipelines

The Skyulf Contributors
Open-source release · AGPLv3 platform · Apache-2.0 core library
Abstract—We present Skyulf, a visual platform for constructing machine learning pipelines whose validation numbers can be trusted. Skyulf separates learn operations (fitted on training data) from apply operations (executed blind on unseen data) at the node level, and statically rejects pipelines that would leak information across the train/validation boundary. We show that a representative leaked pipeline reports 94% validation accuracy while delivering 71% in production, and that Skyulf's guard eliminates this gap by construction. The system comprises a self-hostable platform (canvas, EDA, registry, deployment, drift monitoring) and a pip-installable engine, skyulf-core, with 35 node types and 2,266 passing tests.
Keywords: machine learning pipelines, data leakage, reproducibility, model registry, drift detection

1.Introduction

Machine learning prototypes are easy; trustworthy machine learning systems are not. The most common failure mode is not a weak model but an optimistic one: preprocessing fitted on the full dataset, feature selection performed before the split, or target statistics computed across validation rows. Each produces impressive validation numbers and disappointing production outcomes.

Skyulf addresses this structurally. Rather than asking practitioners to be careful, it encodes the train/serve distinction in the pipeline graph itself. Two artifacts are distributed: the Skyulf Platform (AGPLv3), a self-hostable web application, and skyulf-core (Apache-2.0), a Python 3.12 library implementing the execution engine on pandas or Polars dataframes.

2.The Learn/Apply Split

Every Skyulf node exists in two forms. A learn node observes training data and produces fitted state; the corresponding apply node transforms any dataset using only that state. Validation and serving paths execute apply nodes exclusively. A static check, validate_leakage_safety(), rejects pipelines violating this invariant before training begins:

scorehonest = f ( apply(fit(Xtrain), Xval) ) (1)

and any pipeline computing f over fit(Xtrain ∪ Xval) fails validation. The honest score is smaller — and real.

3.The Pipeline Lifecycle

The platform operationalizes seven stages, each persisted and auditable:

(1) Connect — Postgres, MySQL, Snowflake, BigQuery, or CSV sources become typed dataframes. (2) Explore — EDA dashboards profile distributions, correlations, and missingness before any fitting. (3) Design — the visual canvas composes nodes with the learn/apply split enforced. (4) Train & tune — Optuna, grid, random, or halving search, every trial recorded. (5) Register — each model receives a fingerprint (hash of config, data, and code) and a generated model card. (6) Deploy — REST endpoints or batch jobs serve the identical tested artifact. (7) Monitor — drift detection via KS, PSI, Wasserstein, and KL statistics.

4.Evaluation: The Leakage Gap

We compare two otherwise-identical gradient-boosting pipelines on a tabular classification task. Pipeline L fits its scaler and feature selector on the full dataset; pipeline H (Skyulf) fits on training folds only.

The 23-point gap in pipeline L is not a modeling difference; it is an accounting error. Skyulf's contribution is making the error impossible to commit silently.

5.System Summary

The engine provides 35 transformers and models (imputation, encoding, scaling, selection, ensembles, text/NLP), SHAP-based explanations, and notebook export. The platform adds 11 workspaces — datasource, EDA, canvas, experiments, jobs, registry, deployments, drift, audit log, and settings — over a scikit-learn execution core.

6.Limitations & Availability

Skyulf is honest v0.1 software. It makes no claim of planetary-scale battle-testing; it offers instead a readable codebase, 2,266 passing tests, and complete documentation. The platform is AGPLv3; the core library is Apache-2.0. Self-hosting requires only git clone and docker compose up. A live deployment is available for inspection at api.skyulf.com.

7.Frequently Asked Questions

Is it free? Yes — both licenses permit use, study, and modification. Why not just a notebook? Notebooks are excellent for exploration; they cannot answer which data fitted a given scaler once deployed. Skyulf's registry can, because the answer is recorded at fit time. What does it run on? Python 3.12, scikit-learn, pandas or Polars.
