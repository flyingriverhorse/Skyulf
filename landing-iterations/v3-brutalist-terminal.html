FAQ

What is Skyulf?

Two things sharing one engine: skyulf-core, a Python library giving you a single pipeline API over scikit-learn, and a self-hosted workspace where you build that same pipeline on a canvas.

Do I have to self-host it?

Try the hosted demo first with nothing to install. For real work, docker compose up takes a few minutes. Your data never leaves your machine — usable in hospitals, banks, anywhere the data legally cannot go to a third party.

Is this really free?

Yes. skyulf-core is Apache 2.0 (use it in anything, including closed-source commercial products). The platform is AGPLv3, so improvements to the application itself are shared back.

Can I use it in production?

Perfect for internal tools, research and experimentation. A stable v1.0 for critical production workloads is in progress.

How can I contribute?

Start at GitHub. Code, documentation, bug reports or feature ideas — every contribution helps shape Skyulf.

Ready to build?

Try the demo in your browser, or install the library and start from your next notebook. No signup. No install. No per-prediction bill.
