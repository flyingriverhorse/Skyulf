Data exploration · Pipelines · Training · Comparison · Deployment · Monitoring — one engine, continuous from raw data to monitored production models.

The SKY-ML1 connects the machine-learning lifecycle on a single engine with two first-class, equal interfaces: a self-hosted visual node-canvas platform, and skyulf-core, the independent Apache-2.0 Python package for scripts and notebooks. Visual work exports to Jupyter — full or compact — so nothing is ever trapped in the canvas. Built for data scientists, ML engineers, developers, and product teams who refuse black-box SaaS.

Features

SKY-ML1 integrates the entire lifecycle on one engine. Every item below ships with the part — no separate license tier, no managed-service dependency.

  • Full lifecycle coverage — data exploration, pipelines, training, comparison, deployment, monitoring on one continuous path.
  • Two equal interfaces — the self-hosted visual node-canvas platform and the standalone skyulf-core Python package.
  • Ingestion — CSV, Excel, JSON, Parquet, and S3-compatible storage.
  • Automated EDA — statistical profiling, distributions, correlations, outliers, segmentation, causal discovery, target analysis.
  • Node-based pipelines — preprocessing, feature engineering, splitting, modeling, composed visually or in code.
  • Background training — Celery + Redis workers or background threads; the UI never blocks on a fit.
  • Experiment comparison — runs compared side by side, with a model registry for what survives.
  • Deployment & inference — registered models shipped to serving and queried for predictions.
  • Drift monitoring & diagnostics — deployed models watched for drift, with operational diagnostics and audit history.
  • Jupyter export — visual work exports to notebooks, full or compact. Nothing trapped in the canvas.
  • Storage you choose — SQLite to start, PostgreSQL at scale; local filesystem or S3-compatible storage.
  • Open core — skyulf-core is Apache-2.0; the source, tests, and CI are public.

NOTE: FEATURES LISTED ARE FUNCTIONAL CAPABILITIES OF THE SHIPPED SOFTWARE, VERIFIABLE IN THE HOSTED DEMO AND THE SOURCE REPOSITORY.

Typical Application — Two Reference Designs

One engine, two sockets, equal weight. Wire the SKY-ML1 into your stack through the self-hosted visual platform, through skyulf-core in your own scripts and notebooks, or both.

AC-1

Self-Hosted Visual Platform

The node-canvas interface. Compose preprocessing, feature engineering, splitting, and modeling as nodes; training runs in the background; experiments, registry, deployment, and monitoring live in the same workspace.

$ git clone https://github.com/flyingriverhorse/Skyulf.git $ cd Skyulf $ docker compose up
  • Full stack on your infrastructure via Docker Compose — app, workers, metastore.
  • SQLite metastore to start; PostgreSQL at scale.
  • Local or S3-compatible storage for data and artifacts.
  • Exports to Jupyter notebooks — full or compact — so canvas work stays portable.
Try the hosted demo — no signup
AC-2

skyulf-core Python Engine

The independent package. sklearn-backed estimators with a cohesive, Polars-friendly pipeline layer — preprocessing, classification, regression, clustering, text models, tuning, evaluation, and SHAP explanations behind one composable API. No web platform required.

$ pip install skyulf-core import polars as pl from skyulf import SkyulfPipeline df = pl.read_csv("customers.csv") pipeline = SkyulfPipeline({ "preprocessing": [ {"name": "split", "transformer": "TrainTestSplitter", "params": {"target_column": "purchased", "test_size": 0.2}}, {"name": "impute_income", "transformer": "SimpleImputer", "params": {"columns": ["income"], "strategy": "median"}}, ], "modeling": {"type": "logistic_regression", "params": {"max_iter": 500, "random_state": 42}}, }) pipeline.fit(df, target_column="purchased") pipeline.save("customer_model.pkl")
  • Apache-2.0 Python package, installable from PyPI — works in scripts and notebooks.
  • Builds on scikit-learn and is validated against it; sklearn stays the modeling foundation.
  • Fits once, saves a portable artifact, reloads to predict on new data.
  • Optional extras: [eda], [viz], [tuning], [explainability], [all], and more.
pypi.org/project/skyulf-core

INTEROPERABILITY NOTE: both circuits run the same engine. Visual work exports to Jupyter notebooks (full or compact), so a pipeline sketched on the canvas continues life as code — and skyulf-core code needs no canvas at all. Neither path is a second-class citizen.
