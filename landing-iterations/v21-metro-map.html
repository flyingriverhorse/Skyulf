FAQ

Is Skyulf free to ride?

Yes. skyulf-core is Apache-2.0 and the Platform is AGPLv3. Self-host the whole network: git clone, then docker compose up.

Is it enterprise-ready?

It's honest v0.1 service: a real codebase, 2,266 passing tests, real documentation. We publish the timetable we actually run — no phantom trains.

Why not just use a notebook?

Notebooks are great for sightseeing. In production someone asks "which data fitted this scaler?" — Skyulf's registry answers by construction, like a stamped ticket.

What does it run on?

Python 3.12 on a scikit-learn engine, with pandas or Polars dataframes. Tuning via Optuna, grid, random or halving.
