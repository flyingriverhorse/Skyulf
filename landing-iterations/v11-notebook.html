The 94% that wasn't real

An encoder fitted before the split leaks labels into validation. Your notebook says 94% — production says 71%. Skyulf refuses to run that pipeline.

FAQ

Is it free?

Yes. Platform AGPLv3, library Apache-2.0. Self-hosted, no accounts.

Does it lock me in?

No — pipelines compile to standard scikit-learn. Export a notebook and leave with working code.

Run it locally?

git clone https://github.com/flyingriverhorse/skyulf && cd skyulf && docker compose up

What data?

CSV and Parquet via pandas or Polars, plus text columns for NLP nodes. Python 3.12.
